🌐 **Live Demo:** https://reddiharshavardhan6-commits.github.io/vajra-coupe4-ai-configurator/

---

## 🚘 About the Project

**VAJRA COUPE-4** is a premium luxury sports car concept built as an interactive web experience inspired by **Tesla, Lamborghini Ad Personam, Rolls-Royce, Porsche, and BMW**. It combines futuristic automotive design with AI-inspired customization, immersive 3D visualization, and a cinematic digital driving experience.

Users can personalize the car in real time, explore multiple environments, interact with vehicle hotspots, and seamlessly transition into an immersive test drive—all inside a single responsive web application.

### 🎨 Exterior Customization
- Multiple premium body colors.
- Matte, Gloss, Metallic, Satin, and Carbon finishes.
- Brake caliper color customization.
- Dynamic underglow lighting.

### 💡 Intelligent Lighting System
- LED, Matrix, Laser, and DRL headlights.
- Dynamic taillight animations.
- Smart lighting effects.

### 🪟 Smart Glass & Luxury Interior
- Adjustable window tint slider.
- Panoramic smart glass roof.
- Ambient cabin lighting.
- Windshield Head-Up Display (HUD).
- Heated steering wheel.
- Illuminated luxury logo effects.

### 🌍 Environment Modes
- ☀️ Day
- 🌙 Night
- 🌅 Sunset

### 🎥 Cinematic Camera Modes
- Hero View
- Front View

### 🎮 Immersive AI Test Drive
- Cinematic transition into driving mode.
- Digital speedometer and instrument cluster.
